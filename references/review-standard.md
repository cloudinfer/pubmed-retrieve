# 期刊发表级综述规范

本文件是 Phase 5 产出**可投稿级**系统综述的强制标准。凡是面向期刊投稿、学位论文或正式汇报
的综述，写作与质检都必须以本文件为准，不得按"够用就行"的汇报稿标准放行。

---

## 一、适用报告规范

| 综述类型 | 主报告规范 | 配套工具 |
|---|---|---|
| 干预性疗效系统综述 | PRISMA 2020 | RoB 2 / GRADE |
| **预后与预测模型综述（本 skill 主要场景）** | **PRISMA 2020 + TRIPOD** | **PROBAST（偏倚） + CHARMS（数据提取） + GRADE（确定性）** |
| 诊断准确性综述 | PRISMA-DTA | QUADAS-2 |
| 范围综述 | PRISMA-ScR | — |
| 纳入综述本身的再评价 | PRISMA 2020 | AMSTAR-2 |

本 skill 的检索式默认覆盖预后与治疗应答终点，因此**默认按「PRISMA 2020 + TRIPOD」组合**，
并在讨论中声明该选择。若用户明确是干预比较或诊断准确性，切换对应规范并在方法章节首句写明。

## 三、结构化摘要（强制八要素）

```
背景（Background）：     1–2 句，说明临床问题与现有手段的不足
目的（Objectives）：     1 句，明确 PICO(S) 四要素
方法（Methods）：        数据源、检索时间窗与日期口径、筛选与提取方式、
                        偏倚风险与确定性评价工具、方案注册号
结果（Results）：        识别 N → 题录排除 N → 全文评估 N → 最终纳入 N；
                        主要主题分布；证据确定性结论
结论（Conclusions）：    1–2 句，给出可执行的判断与证据边界
注册（Registration）：   PROSPERO 编号或"未注册"声明
```

摘要中**所有数字必须与 `review_evidence.json` 一致**，质检脚本会逐项比对。

## 四、引用规则（最高优先级）

1. **每条实质性论断必须有引用**。连续 ≥ 200 字无任何引用的段落判为 P0。
2. **禁止 vibe citing**：引用编号必须对应 `corpus` 中该 PMID 的真实题录，
   且论断内容必须在该文献题名或摘要中有对应表述。不得凭印象指派文献。
3. **引用密度**：正文每千字 ≥ 8 条引用；方法章节可豁免，结果章节必须 ≥ 12 条/千字。
4. **参考文献格式**：Vancouver，末尾附 `PMID: xxxxx`。参考文献全部由脚本从 CSV 生成，
   禁止手抄（手抄必错）。
5. **不引用未纳入文献**：正文不得出现 corpus 之外的 PMID；背景性常识可用教科书或指南，
   但必须在参考文献中列出完整条目。

## 五、语言与表述禁忌

| 禁止 | 改为 |
|---|---|
| 证明了 / 明确表明 / 一定 / 显著优于 | 提示 / 倾向于 / 在本次检索范围内 / 多数研究报告 |
| 高水平期刊 / 权威研究 / 重要发现 | 直接陈述研究设计与样本量（无 IF/引用数据时不评价质量） |
| 发表时间 | 入库日期（EDAT） |
| 分类 | 主题分桶 |
| 所有研究均 / 无一例外 | 在纳入的 N 篇中，有 M 篇报告了… |
| 首次证明 / 突破性 | 删除（无法从题录层面证实） |

**时态与语态**：方法与结果用过去时，公认事实与结论用现在时；避免"我们认为"等主观标记。

## 七、偏倚风险：PROBAST 四域（预测模型综述）

| 域 | 关键信号问题 | 典型降级原因 |
|---|---|---|
| 研究对象（Participants） | 纳入是否连续、数据是否来自真实临床场景 | 单中心回顾性、选择偏倚 |
| 预测因子（Predictors） | 定义与测量是否一致、是否在建模前可获得 | 分割与特征提取由同一人完成 |
| 结局（Outcome） | 定义与判定是否盲法、随访是否充分 | 终点判定未盲法、随访时间不足 |
| 分析（Analysis） | 样本量是否充足、缺失数据处理、是否做过外部验证 | 仅内部验证、无外部验证、未报告校准 |

每个域判 低 / 高 / 不清楚，**整体偏倚风险取各域最差值**。题录层面只能给出"待全文评估"占位，
**不得用摘要推断填充**（这是综述最常见的造假点）。

## 八、GRADE 确定性五维降级因素

偏倚风险 / 不一致性 / 间接性 / 不精确性 / 发表偏倚。
观察性研究起点为"低确定性"，满足升级条件（大效应量、剂量反应、残余混杂）可升级。
预测模型综述额外考察：验证方式（内部/外部/多中心）与校准报告完整性。

## 九、声明要件（缺一不可）

1. **方案与注册**：PROSPERO 编号；未注册须明确声明"本综述未预先注册方案"。
2. **资助**：基金编号或"未接受任何资助"。
3. **利益冲突**：逐一声明或"所有作者声明无利益冲突"。
4. **数据可得性**：提取表与数据集的获取方式（仓库链接 / 通讯作者索取）。
5. **作者贡献**：按 CRediT 分类列明。
6. **AI 使用声明**：必须写明 AI 参与了哪些环节（检索式生成、题录筛选、证据分级、
   初稿撰写），并声明所有数值与引用已由作者核对、AI 不对内容负责。
7. **全文获取的局限**：本 skill 仅基于题录与摘要，须声明"证据分级与偏倚评估为暂定，
   全文复核后需更新"。
